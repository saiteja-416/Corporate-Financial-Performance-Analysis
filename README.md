# 📊 Corporate Financial Performance Analysis | Power BI Project

## 📌 Project Overview

This project focuses on analyzing corporate financial statements using Power BI to uncover actionable insights related to revenue growth, profitability, cash flow management, and balance sheet performance.

The objective is to transform raw financial data into interactive and business-ready dashboards that enable stakeholders to monitor company performance, evaluate financial health, and support data-driven decision-making.

---

## 🎯 Objectives

- Analyze company-level financial performance across multiple years
- Evaluate revenue, net income, assets, liabilities, and cash flow trends
- Identify top-performing and underperforming companies using financial KPIs
- Monitor balance sheet strength through debt-to-equity and asset growth metrics
- Create interactive dashboards for executive-level decision-making
- Demonstrate real-world Power BI data modeling and visualization skills

---

## 🗂 Dataset Description

The dataset contains corporate financial statement data including:

- Revenue
- Net Income
- Assets
- Liabilities
- Retained Earnings
- Operating Cash Flow
- Investing Cash Flow
- Financing Cash Flow
- Shareholder Equity
- Debt-to-Equity Ratio
- Gross Profit Margin
- Capital Expenditure
- Company Stock Symbols
- Financial Year Information

The dataset is used for educational and analytical purposes to perform comprehensive financial performance analysis.

---

## 📈 Key Insights

- Several companies demonstrated consistent revenue growth despite fluctuations in net income.
- Asset growth does not always translate into profitability improvements.
- Some organizations maintain strong operating cash flow despite lower net income.
- Debt-to-equity analysis highlights companies with stronger financial stability.
- Cash flow analysis reveals organizations facing free cash flow challenges despite revenue growth.
- Revenue leadership and profitability leadership often differ across companies.
